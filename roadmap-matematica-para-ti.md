# Roadmap de Matemática para TI 🧭

Um caminho estruturado para quem está começando na área de TI e quer construir uma base matemática sólida. Pensado para ser seguido em ordem, mas você pode ajustar o ritmo conforme sua área de interesse.

---

## 🟢 Fase 0 — Base (Ensino Médio revisado)
**Duração estimada: 2-4 semanas**

Antes de entrar na matemática "de TI", vale reforçar:
- Operações com frações, potências e raízes
- Equações do 1º e 2º grau
- Funções (afim, quadrática, exponencial, logarítmica)
- Trigonometria básica (seno, cosseno, tangente)
- Sistemas de numeração: decimal, **binário**, **octal**, **hexadecimal**

**Canais sugeridos:** Prof. Ferretto, Matemática Rio, Curso em Vídeo (Gustavo Guanabara)

> 💡 Se você já domina essa base, pode pular direto pra Fase 1.

---

## 🔵 Fase 1 — Lógica e Matemática Discreta
**Duração estimada: 1-2 meses**
**Por quê:** é a base de programação, algoritmos e ciência da computação.

- Lógica proposicional (tabelas-verdade, conectivos, tautologias)
- Álgebra booleana (portas lógicas AND, OR, NOT, XOR)
- Teoria dos conjuntos
- Relações e funções
- Técnicas de contagem (permutação, combinação, arranjo)
- Recursão e indução matemática
- Introdução a grafos e árvores

**Canal recomendado:** canal *Matemática Discreta* (Prof. Marcelo Gama) — cobre praticamente tudo isso em sequência.

**Aplicação prática:** estruturas de dados, algoritmos, circuitos digitais.

---

## 🟡 Fase 2 — Álgebra Linear
**Duração estimada: 1-2 meses**
**Por quê:** essencial para computação gráfica, machine learning e processamento de dados.

- Vetores e operações vetoriais
- Matrizes (soma, multiplicação, transposta, inversa)
- Determinantes
- Sistemas lineares
- Espaços vetoriais (conceito introdutório)
- Autovalores e autovetores (mais avançado — necessário só se for para IA)

**Canais sugeridos:** Prof. Ferretto, Matemaníaca (Juju), playlists de universidades (USP, UFRJ, UFMG)

**Aplicação prática:** gráficos 3D, redes neurais, compressão de imagens.

---

## 🟠 Fase 3 — Cálculo
**Duração estimada: 2-3 meses**
**Por quê:** necessário para otimização, aprendizado de máquina e processamento de sinais.

- Limites e continuidade
- Derivadas e regras de derivação
- Aplicações de derivadas (taxas de variação, otimização)
- Integrais (noção introdutória)
- Cálculo multivariável (gradientes) — **só se for seguir IA/ML**

**Canais sugeridos:** Prof. Ferretto (Cálculo 1 completo), Matemática Rio

**Aplicação prática:** treinamento de modelos de IA, algoritmos de otimização.

---

## 🔴 Fase 4 — Probabilidade e Estatística
**Duração estimada: 1-2 meses**
**Por quê:** fundamental para análise de dados, ciência de dados e redes.

- Probabilidade básica
- Distribuições (normal, binomial)
- Medidas de tendência central e dispersão (média, mediana, desvio padrão)
- Correlação e regressão
- Probabilidade discreta (conecta com a Fase 1)

**Canais sugeridos:** buscar "estatística para ciência de dados" + universidades federais

**Aplicação prática:** machine learning, análise de dados, testes A/B, segurança de redes.

---

## 🟣 Fase 5 — Especializações (escolha conforme sua área)

| Área | O que estudar |
|---|---|
| **Segurança / Criptografia** | Teoria dos números, aritmética modular, corpos finitos, álgebra abstrata |
| **IA / Machine Learning** | Álgebra linear avançada, cálculo multivariável, estatística bayesiana |
| **Computação gráfica / Games** | Geometria analítica, trigonometria avançada, álgebra linear (transformações) |
| **Redes** | Teoria dos grafos, probabilidade aplicada |
| **Banco de dados** | Álgebra relacional, lógica de conjuntos |

---

## 📌 Dicas gerais para seguir o roadmap

- Não tente estudar tudo simultaneamente — siga a ordem das fases
- Pratique com exercícios aplicados à programação (ex: implementar um algoritmo que usa o conceito que você acabou de aprender)
- Sites como Khan Academy (também tem em português) complementam bem os vídeos
- Refaça exercícios de matemática discreta junto com lógica de programação — eles se reforçam mutuamente

---

## 🎯 Resumo visual do caminho

```
Fase 0: Base           →  revisão fundamental
Fase 1: Lógica/Discreta →  algoritmos, estruturas de dados
Fase 2: Álgebra Linear  →  gráficos, ML
Fase 3: Cálculo         →  otimização, ML
Fase 4: Probabilidade   →  dados, estatística
Fase 5: Especialização  →  escolha sua trilha
```

**Tempo total estimado:** 6-9 meses estudando de forma consistente (poucas horas por semana), podendo ser mais rápido se dedicar mais tempo diário.
